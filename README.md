# Prime Minister Burnham: Find the Money

A mobile-first satirical web game prototype built with React, TypeScript, Tailwind CSS, Vite, and Framer Motion.

## Development

Install dependencies:

```bash
npm install
```

Start the local development server:

```bash
npm run dev
```

Create a production build:

```bash
npm run build
```

Preview the production build locally:

```bash
npm run preview
```

## Gameplay prototype

The current app includes the first playable client-side loop from the BRD:

- Opening Treasury briefing
- Random spending commitment with a clear funding target
- One-click department cuts with immediate consequences
- Tax-raising cards, including Wealth Tax
- Funding, productivity, and Tax Burden HUD meters
- Treasury Report end screen with score, rating, choices, and headline
